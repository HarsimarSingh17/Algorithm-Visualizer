# 🚀 Algorithm Visualizer

An interactive web application designed to make learning algorithms easier through visualizations and animations.

Algorithm Visualizer helps users understand how algorithms work by presenting their execution visually, making complex concepts more intuitive and engaging.

## ✨ Features

- **Sorting Visualizer** — Visualize sorting algorithms and observe how elements are compared and rearranged.
- **Pathfinding Visualizer** — Explore grid-based pathfinding and understand how algorithms navigate between nodes.
- **Interactive UI** — A clean and intuitive interface for exploring algorithms.
- **Visualization Controls** — Customize supported visualization settings to explore algorithms at your own pace.

## 🛠️ Tech Stack

- **HTML5** — Structure and content.
- **CSS3** — Styling, layouts, and animations.
- **JavaScript (Vanilla JS)** — Algorithm implementation, DOM manipulation, and interactive functionality.
- **Git & GitHub** — Version control and project management.

## 📂 Project Modules

### 1. Sorting Visualizer

Visualize sorting algorithms step by step and observe how an array changes as elements are compared and rearranged.

### 2. Pathfinding Visualizer

Explore pathfinding on a grid and understand how algorithms navigate from a starting node to a destination.

## 🚀 Getting Started

### Prerequisites

A modern web browser and a code editor such as [Visual Studio Code](https://code.visualstudio.com/).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/HarsimarSingh17/Algorithm-Visualizer.git
```

**2. Navigate to the project directory**

```bash
cd Algorithm-Visualizer
```

**3. Run the application**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code for a local development server.

No framework installation or build process is required.
