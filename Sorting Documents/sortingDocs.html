Bubble Sort
Bubble Sort is a basic sorting algorithm that arranges elements by comparing adjacent elements and swapping them whenever they are in the wrong order. It repeatedly passes through the array until all elements are sorted. In each pass, adjacent elements are compared, and the larger element is moved towards the end of the array. After every pass, the largest unsorted element reaches its correct position. The process continues with the remaining unsorted elements until the entire array is sorted. Bubble Sort is easy to understand and implement, but it is less efficient for large datasets due to its high time complexity.
Codes below :
Time Complexity: O(n2)
Space Complexity: O(1)

Advantages of Bubble Sort: 

                        1. It is simple to learn and implement, making it suitable for beginners.
                        2. It sorts elements in place, so it requires very little extra memory.
                        3. It is a stable sorting algorithm that preserves the relative order of equal elements.
                        4. Its optimized version can perform efficiently on small or nearly sorted arrays.

Disadvantages of Bubble Sort: 

                        1. It has an average and worst-case time complexity of (O(n2)), making it inefficient for large datasets.
                        2. It may require many comparisons and swaps to arrange elements in the correct order.
                        3. It is generally slower than algorithms such as Merge Sort and Quick Sort for larger inputs.
                        4. It is rarely used in practical applications because more efficient sorting algorithms are available.
Selection Sort
Selection Sort is a simple sorting algorithm that sorts an array by repeatedly finding the smallest element from the unsorted part and placing it at the beginning of that part. It divides the array into sorted and unsorted sections and gradually expands the sorted section until all elements are arranged in ascending order. In each pass, the algorithm searches for the minimum element in the unsorted part of the array. The minimum element is swapped with the first element of the unsorted section. After each pass, one more element is placed in its correct position, expanding the sorted section. The process continues until the entire array is sorted. Selection Sort is easy to understand and uses very little extra memory, but it is inefficient for large datasets.
Codes below :
Time Complexity: O(n2)
Space Complexity: O(1)

Advantages of Selection Sort: 

                        1. It is simple to understand and implement, making it suitable for beginners.
                        2. It sorts elements in place and requires very little extra memory.
                        3. It performs fewer swaps compared with many other simple sorting algorithms.
                        4. It works well for small datasets.

Disadvantages of Selection Sort: 

                        1. Its best, average, and worst-case time complexity is O(n2).
                        2. It is inefficient for large datasets.
                        3. It is generally not a stable sorting algorithm in its standard implementation.
                        4. It does not adapt well to arrays that are already sorted.
Insertion Sort
Insertion Sort is a simple sorting algorithm that arranges elements by taking one element at a time and inserting it into its correct position in the already sorted part of the array. It divides the array into sorted and unsorted sections and gradually builds the sorted section from left to right. The algorithm starts with the first element, which is considered sorted. In each pass, the next element is selected as the key and compared with the elements before it. All elements greater than the key are shifted one position to the right to make space for it. The key is inserted into its correct position, and the sorted section grows by one element. The process continues until all elements are sorted. Insertion Sort is efficient for small or nearly sorted arrays but is less suitable for large datasets.
Codes below :
Time Complexity: O(n2) (O(n) in the best case scenario)
Space Complexity: O(1)

Advantages of Insertion Sort: 

                        1. It is simple to understand and implement, making it suitable for beginners.
                        2. It requires very little extra memory because it sorts elements in place.
                        3. It performs efficiently on small or nearly sorted arrays.
                        4. It is a stable sorting algorithm that preserves the relative order of equal elements.

Disadvantages of Insertion Sort: 

                        1. Its average and worst-case time complexity is O(n²), making it inefficient for large datasets.
                        2. It may require many comparisons and shifts when elements are in reverse order.
                        3. It is generally slower than advanced sorting algorithms such as Merge Sort and Quick Sort for large inputs.
                        4. Its performance decreases as the size of a randomly ordered array increases.
Quick Sort
Quick Sort is an efficient sorting algorithm that arranges elements by selecting a pivot element and partitioning the array around it. Elements smaller than the pivot are placed on its left, while larger elements are placed on its right. The same process is then applied recursively to the left and right subarrays until the entire array is sorted. The algorithm selects a pivot element from the array. It partitions the array by placing smaller elements before the pivot and larger elements after it. The pivot reaches its correct sorted position after partitioning. The process repeats recursively on the left and right subarrays until the array is completely sorted. Quick Sort is generally fast in practice, especially for large datasets, and can sort elements in place.
Codes below :
Time Complexity: O(nlogn) (O(n2) in the worst case scenario)
Space Complexity: O(logn) (O(n) in the worst case scenario)

Advantages of Quick Sort: 

                        1. It is efficient for large datasets in average cases.
                        2. It can sort elements in place, requiring little extra memory for partitioning.
                        3. It follows the divide-and-conquer approach, breaking a large problem into smaller subproblems.
                        4. It often performs well in practical applications due to good cache efficiency.

Disadvantages of Quick Sort: 

                        1. Its worst-case time complexity is O(n2).
                        2. Its performance depends on the choice of pivot.
                        3. It uses recursion, which can cause stack overhead.
                        4. Standard Quick Sort is generally not a stable sorting algorithm.
Merge Sort
Merge Sort is an efficient sorting algorithm that uses the divide-and-conquer technique to arrange elements in ascending order. It divides the array into smaller subarrays until each subarray contains only one element. These subarrays are then merged back together in sorted order until the entire array is sorted. In each step, the array is divided into two halves. The process continues recursively until the smallest subarrays are reached. The subarrays are then merged by comparing their elements and placing them in the correct order. This process continues until a single sorted array is formed. Merge Sort is efficient for large datasets and provides consistent performance, but it requires extra memory for merging.
Codes below :
Time Complexity: O(nlogn)
Space Complexity: O(n)

Advantages of Merge Sort: 

                        1. It efficiently sorts large datasets with a time complexity of O(n log n).
                        2. It is a stable sorting algorithm that preserves the relative order of equal elements.
                        3. It provides consistent performance in the best, average, and worst cases.
                        4. It works well for sorting linked lists and large amounts of data.

Disadvantages of Merge Sort: 

                        1. It requires additional memory for merging subarrays.
                        2. It can be more complex to implement than simple sorting algorithms.
                        3. For small arrays, it may have more overhead than algorithms such as Insertion Sort.
                        4. Its standard array implementation is not an in-place sorting algorithm.
